## Architecture and Acceptance

- Hosted generation replaces local generative SLMs, not local Laya. Support **Gemini API, OpenAI Chat Completions and OpenAI Responses** through separate protocol adapters and one shared agent runtime. Provider, endpoint, model ID and credential are explicitly configured; no hidden provider/model substitution.
- Current qualification candidates are Gemini 3.5 Flash Lite and DeepSeek V4.1 Flash via OpenCode Go. Owner explicitly removed Gemma 4 26B from the current evaluation because rate-limit waiting is unsuitable for the intended user experience; preserve its earlier trials without claiming intrinsic capability failure. Support is discovered/verified, not inferred from a model name or compatibility label. OpenCode Go uses its verified Go route, not the unrelated Console `/inference` route.
- A user request may require several LLM/tool turns. Feed actual tool results back, retain required protocol continuation items, ask for clarification when necessary and verify application postconditions before reporting completion. Skill instructions cannot grant authority.
- Masking is a mandatory **local pre-egress boundary** on user input, selected context, history and tool results. Never make privacy depend on an LLM remembering to call a masking tool. Detect/minimize sensitive amounts, dates, accounts, identities and bank text; keep reversible mappings local and scoped. Unknown/ambiguous mappings or masking failure block external inference while preserving manual work.
- Preserve exact local integer-VND/date/time/source-span semantics. The model must still reason about equality, ordering and relative-time relationships needed by the workflow; tokenization that destroys those relationships is not an acceptable privacy implementation. Rehydrate validated values locally before invoking typed application commands; never accept arbitrary model text as a mapping key or authority.
- Scope/revisions/operation identities come from trusted runtime/application state where possible, not model guesses. Only complete validated allowlisted calls execute. No financial confirmation, deletion, arbitrary SQL, shell, arbitrary filesystem access, general plugin system or device automation.
- Durable run state and operation results survive retry/cancel/restart without duplicate effects. Conversation retention is explicit and separate from business captures and effect journals; no hidden reasoning or raw financial diagnostic logs. Sensitive protocol continuation data, if required, stays protected, task-scoped and retention-bounded.
- Do not impose the old shared 2048-token cap on large reasoning models. Freeze adequate per-model generation/reasoning budgets based on actual API semantics. Still bound total turns, calls, time, context and user-visible resource/cost policy. Truncation is an explicit incomplete-budget outcome, never silent success or evidence of an intrinsic model ceiling.
- Provider prices/free quotas are variable. Owner reports DeepSeek approximately USD 0.0001–0.001/request and Google free quotas approximately 14K/500 requests/day for Gemma/Gemini respectively; these are planning context, not verified service guarantees or acceptance limits. Measure actual usage where exposed, handle 429/account errors honestly and do not prioritize local SLM to save cost.
- Privacy masking is data minimization, not a claim of anonymity or no remote processing. Disclose selected endpoint and residual contextual exposure before real-data cloud use. No silent inference upload; no bundled developer keys.
