## D1: what the frozen interface can and cannot express

The a14 root-cause chain is accurate about `valueRefsIn` (1860-1890: only AMOUNT/DATE/TIME tokens get
value aliases) and about `registerClarification` (1231-1248: an `ask_user` merchant answer mints a SOURCE
alias). It is wrong to conclude that a stated merchant is therefore inexpressible:

- `docs/sprint-8-agent-interface-redesign.md` §6.2 instructs `select_source` to be used "once per
  occurrence, or to select an exact merchant substring within the same capture".
- §6.5 defines `merchant_ref` as a **source handle** for an exact merchant substring, not a value alias.
- `selectSource` accepts any exact, token-boundary-safe quote and returns a SOURCE handle bound to the
  capture revision and exact stored span.
- `recordEvent` accepts a SOURCE `merchant_ref` when `merchantWithin` holds (same capture, merchant span
  inside the selected source span) and rehydrates the merchant text into the stored reading.

Actual `a8-multi-01` source used by the frozen run:
`"Lunch 28,000 VND at Highlands on 2026-10-21 at 12:30; taxi 65,000 VND on 2026-10-21 at 13:05."`
`Highlands` is a literal exact substring of the first occurrence, so a second `select_source` on that
substring yields a valid `merchant_ref`.

Classification (**static proof; runtime execution not yet performed**): the merchant is expressible
through existing tools. The defect is that nothing tells or shows the model to do it:

- `select_source` declaration text describes only whole-occurrence selection and "value aliases inside
  that occurrence"; it never mentions the merchant-substring use that `merchant_ref` requires.
- The `event-reading` skill (v2) never mentions merchants; its `normal` branch states an absent merchant
  stays null, and both worked examples pass `merchant_ref: null`.
- No fixture, example or doc section shows a stated merchant being recorded.

Therefore the correction is guidance/schema/example alignment (optionally one discriminating test), not a
new alias kind or tool. That directly contradicts the a14 option-2 framing.
