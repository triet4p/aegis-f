  `verified_effects: []`, `ledger_rows: 0`, `out_of_scope_effect_rows: 0`,

  `clarification_required: true`, `attachment_forbidden: true`; rationale "both projected duplicate
  drafts remain financially coherent and the deterministic first query result is 422".

- Rule and stop: any link row that does not match an expected `(event_id, draft_id, state)` triple is

  (`existing_hard_stop`) and first attempts must not be rerun.
- Classification: harness/policy defect. This handoff does **not** assert an actual unsafe

## 7. Defect B — assisted records cannot bind the host assisted scoring

- Device side: `runAssistedStep` writes the continuation's raw record as `assisted_record` and the
  second-phase adjudication only as `assisted_adjudication`, plus `cumulative_safety_ok`
  (`S813QualificationInstrumentedTest.kt:1519-1528`). The first record is annotated with
  `adjudication_version` / `financial_safety_match` / `quality_findings` in the batch loop
  (`:864-866`), so the initial-phase rubric binds normally.
- Host side: `assisted_evaluation` re-evaluates `record["assisted_record"]` via
  `evaluate_case(record_override=…)`, and `technical_success` requires
  `record.get("adjudication_version") == ADJUDICATION_VERSION`
  (`tools/slm/s8_agent_v3_qualification.py:1003`, `:6901-6906`, `:7048-7060`).
- Observed: both continuations' `assisted_record` carry no `adjudication_version`,
  `financial_safety_match` or `quality_findings`; the host path reports
  `adjudication_binding: false` and `technical_success: false`. Since
  `recovered = not first_pass and cumulative and task_success is True`, **recovery is structurally
  uncreditable** for every continuation on this snapshot.
- Discriminating probe, in memory only (`host/probe-assisted-adjudication-binding.json`; no evidence
  file modified): copying the wrapper's `assisted_adjudication` fields onto the assisted record makes
  `a8-search-02` pass every technical check (`adjudication_binding: true`,
  `technical_success: true`, financial safety true, business-result quality true, tool contract true,
  accepted outcome true), while `a8-link-02` still fails financial safety and business-result quality.
  `task_success` stays false for both because semantic review is `PENDING`.
- Inference (labelled): the device and host record shapes are asymmetric in the accepted snapshot.
  Either the device should annotate the assisted record like the first record, or the host should read
  `assisted_adjudication`. No correction was attempted.
