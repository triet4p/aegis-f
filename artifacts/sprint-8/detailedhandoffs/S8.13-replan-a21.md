## Decisions that matter to a successor

1. **Fixed shape-only feedback, not representation change.** The a20 assessment and the log entry
   explain why: aliases/prose narrowing do not remove the refusal class and lose foreign detection;
   fixed feedback targets the measured trigger and cannot echo refused text. The notice deliberately
   contains no `⟦…⟧` example, so the model cannot copy a new unissued shape.
2. **One repair, terminal otherwise.** Eligibility is `UNKNOWN_TOKEN` from the *body scan* only
   (`HostedProviderFailure.PrivacyBlocked`). The post-parse `maskTurnOrBlock` path stays terminal.
   The refused attempt increments `run.turns`, so a run at its turn bound repairs nothing.
3. **No-effect evidence is derived from the run's own read-only route**, never model text:
   - `EmptySearch`: every `list_drafts` page claim under one filter with `scope_exhausted`, the union
     of page ids empty, and a live re-read returning exactly that empty set.
   - `LinkNoMatch`: same complete scope, every inspected pair non-`ELIGIBLE`, inspected draft ids ⊇
     scoped ids, and a live re-read of revision + eligibility + absence of a PROPOSED/ACCEPTED link.
   - `PolicyRefusal`: host-declared `NO_EFFECT_AUTHORIZED`, zero mutation dispatches.
   - A settlement is never emitted for an intent that already has a verified effect.
4. **Repaired refusal is not an unrepaired provider failure** in scoring, but the refused exchange is
   still retained as evidence; a case with no accepted turn still fails technically.

## The two plumbing defects found by the approved run

1. **Run directory name.** `S813QualificationInstrumentedTest.kt:620` writes
   `"$attemptId/$snapshotId/$profile/reproduction-blocked-token"` while the scorer's
   `REPRODUCTION_RUN_NAME` is now `diagnostic-repair-nomatch-clarify`. The scorer therefore reported
   `reproduction attempt directory was not present after instrumentation`. Records exist on the
   phone and were pulled read-only with `run-as` into
   `evidence/S8.13-replan-a21/run-retained-01/` (`live-run.json`, four case records, one sidecar).
2. **Stop rule counts the repaired refusal.** `diagnosticStopReason` (line 761) returns
   `provider_error` for any retained provider turn with `provider_failure`. Consequence: after
   `a8-adv-03` the runner marked `a8-nomatch-01`, `a8h-nomatch-01`, `a8-link-02`
   `not_run_safety_stop`, so live no-match/clarify behaviour is unmeasured. Both defects are outside
   the repair runtime and were left unchanged because the source is frozen.
