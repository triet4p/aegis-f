  bytes and refuses to trust a self-declared pass record: origin freeze/build/case mapping/static
  preflight/device preflight/path-identity preflight; pass-1 host record and live run; the debug
  session and all 24 per-case capture trees (`case.json`, `effects.json`, `turns.jsonl`, optional
  `exchanges.jsonl`); 24 case records and provider sidecars; 24 assisted wrappers, decisions and
  ready records; 24 feedback requests plus sidecars; the actual response for each
  `feedback_applied` slot; and the existing semantic adjudication. Each path/size/SHA-256 is
  frozen, and the manifest carries its own canonical digest.
- **Completeness and binding checks.** The origin pass 1 must be a complete measured repetition
  (24/24 `hosted_run_recorded`, full live run, clean host record, passed path identity), the
  origin fixture/scorer must equal the current ones, the origin APKs must equal the rebuilt APKs,
  every assisted wrapper must bind its exact first-record digest, every decision/ready/request/
  response must match, and every retained raw byte is re-hashed. A missing assisted trace, changed
  raw hash, changed APK/fixture/scorer, incomplete pass or wrong identity rejects before any
  credential load or device effect.
- **Source binding allowlist.** Origin and current source manifests must have identical key sets.
  Every differing path must be in `RETAINED_ORIGIN_HOST_ONLY_SOURCE`, which is exactly
  `tools/slm/s8_agent_v3_qualification.py` (the host invocation/provenance bridge). This is not a
  blanket allowance: an unexpected changed/added/removed path rejects. Docs, README and the
  changelog are outside the frozen source manifest (`SOURCE_DIRS` are the app source trees and
  `SOURCE_FILES` is explicit), so they cannot mask source drift; they also carry no frozen claim.
- **Plan and selection.** Passes: pass 1 `case_ids: []`, `slot_order` = the 24 retained ids,
  measured 0/retained 24; passes 2 and 3 `case_ids`/`slot_order` = the frozen 24-case order,
  measured 24/retained 0. Total 72, measured 48, retained 24; the builder asserts the arithmetic.
- **Preflight/freeze/run/score wiring.** Preflight writes `snapshot-N/retained-origin-manifest.json`
  and records its summary in the mapping/static preflight; strict preflight re-derives the manifest
  and rejects drift; freeze embeds the full manifest and plan and strict freeze re-derives it;
  `run --pass-number 1` is refused by name; pass 2 treats the retained origin host record as the
  immutable predecessor and refuses any new pass-1 folder/host record; `score` uses the origin host
  record and run folder for retained rows and requires new host records only for passes 2-3.
- **Semantics without regrade.** Retained pass-1 decisions are read from the frozen origin
  adjudication (a74: the owner-commissioned partial review; a71: its per-pass decision file). They
  are frozen in the manifest and re-used verbatim. `--semantic-reviews` supplies passes 2-3 only;
  a pass-1 entry is rejected as a would-be regrade.
- **Assisted evaluation.** Retained wrappers are read from the origin run folder and their hashes
  must match the frozen origin manifest. The frozen denominators are unchanged: assisted PASS@2 is
  over 72 slots, recovery is `recovered / initial failures` (a74 pass 1: 1 recovered / 4 initial
  failures = 25%, distinct from the 1/72 assisted gain). First-phase cumulative-safety verdicts
  stay immutable.
- **Read-only validation action.** `retained-plan` calls strict freeze, re-derives the origin,
  prints the exact slot selection and exits without touching the device or provider.
- **Selfcheck coverage.** `selfcheck` adds: retained-24/48 plan; frozen-manifest mutation rejection
  for APK/fixture/scoring/raw hash/assisted trace/missing slot; a real rebuilt-APK mismatch; a
  swapped fixture/scorer; a hardlink mirror of the a74 origin with one assisted wrapper physically
  removed; and an unbound semantic-review row.
