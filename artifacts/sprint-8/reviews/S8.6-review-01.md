## 3. Substantive Verification & Acceptance Criteria Audit

### 3.1 Mandatory Local Pre-Egress Boundary on Every Outbound Path

- **Seam and No-Bypass Production Path:** `MaskedHostedGateway` wraps `HostedGenerationAdapter` privately. Production callers cannot access the underlying adapter directly.
- **Outbound Paths Covered:**
  - `begin(systemInstruction, userInstruction)`: both instructions are masked through `boundary.maskOutbound(..., MaskedPath.CONTEXT)`.
  - `continueWithToolResults(conversation, results)`: tool results are masked via `boundary.maskToolResultJson(outputJson)` which recursively parses and masks string values in the JSON observation, rejects non-finite numbers (`NaN`/infinite), and enforces valid JSON object structure.
  - `maskContext(text)`: outbound context excerpts, drafts, and note texts are masked before joining prompts.
- **Wire Interception Proof:** Over a `RecordingTransport`, all 3 supported protocols (`GEMINI_GENERATE_CONTENT`, `OPENAI_CHAT_COMPLETIONS`, `OPENAI_RESPONSES`) were intercepted across two-turn exchanges (prompt turn and tool-result continuation turn). None of the fixture's sensitive literals (`15,000,000`, `15000000`, `2026-10-25`, `2026`, `10-25`, `4821`) appeared in any request payload.

### 3.2 Protocol Continuations and Native Signatures

- **Continuation Integrity:** Native protocol continuation items (Gemini `thoughtSignature` and `functionCall.id`, OpenAI Chat Completions `tool_call.id`, OpenAI Responses `reasoning` and `function_call.call_id`) are held in `HostedConversation` state untouched. They are not stripped, altered, or re-masked on subsequent turns.
- **Idempotent Masking:** `SensitiveVault.applyMask()` identifies previously minted tokens matching `TOKEN_PATTERN` and protects their spans before running detection regexes, preventing double-masking of conversation history or tool exchanges.

### 3.3 Scoped Value Mapping, Types, and Semantics

- **Deterministic Local Regex:** No specialist local SLM or external service is used; detection relies on deterministic regexes (`DATE_PATTERN`, `TIME_PATTERN`, `GROUPED_AMOUNT_PATTERN`, `UNIT_AMOUNT_PATTERN`, `ACCOUNT_HINT_PATTERN`, `BARE_DIGITS_PATTERN`, `BANK_CODE_PATTERN`).
- **Exact Typed Representations:**
  - `rehydrateAmount`: decodes whole dong to exact `Long` integer VND without floating-point conversion.
  - `rehydrateDate`: decodes to exact `YYYY-MM-DD` ISO calendar string.
  - `rehydrateTime`: decodes to exact `HH:mm` 24-hour wall-clock string.
  - `rehydrateAccount` / `rehydrateBank`: decodes to exact digit runs and alphanumeric bank codes.
- **Relations Preserved Without Cleartext:**
  - **Equality:** identical canonical values within a session vault resolve to the identical token.
  - **Ordering:** `compareAmounts()`, `compareDates()`, and `compareTimes()` allow host-side comparison without leaking underlying values to external logs or prompts.
- **Overlap & Priority:** Greedy longest match first with priority ordering ensures `UNIT_AMOUNT_PATTERN` (e.g. `15000000 VND`) takes precedence over `BARE_DIGITS_PATTERN` (account-like run), and compound dates/times take precedence over sub-spans.

### 3.4 Inbound Validation, Authority, and Effect Rehydration

- **Fail-Closed Gate:** Inbound model text is scanned before dispatch:
  - Raw sensitive literals present in inbound model text trigger `InboundRefusal.RAW_LITERAL_EGRESS`.
  - Well-formed tokens belonging to other sessions trigger `InboundRefusal.FOREIGN_TOKEN`.
  - Unmapped or forged token-like spans trigger `InboundRefusal.UNKNOWN_TOKEN`.
  - In `MaskedHostedGateway.generate()`, an inbound turn failing scan results in `HostedTurnFinish.Incomplete("masking_blocked")` with empty tool calls and null continuation.
- **Application Effect Verification:** In `MaskedApplicationEffect`:
  - `captureId` is verified against session `scope.captureIds`.
  - Source spans (`spanStart`, `spanEnd`) are verified against `captureText` bounds.
  - `verifySpanAlignment` renders the source slice with a non-minting `maskedPreview()` to ensure tokens and surrounding words align without polluting the vault on refused writes.
  - `storeMaskedReading` in `MaskedBoundaryTest` executes against a real Room SQLite database through `WorkflowCommandService`: records stored reading with exact `15,000,000` VND, `2026-10-25`, spans `0..35`, 1 `workflow_operations` record, and 0 ledger transactions.

### 3.5 Disclosures and Privacy Boundaries

- **Data Minimization vs. Anonymity:** `CHANGELOG.md` and `SensitiveVault` explicitly disclose that masking minimizes sensitive entities but does not provide complete anonymity: structure, message length, and non-sensitive phrasing remain visible to hosted providers.
- **Leak and Export Protection:** `SensitiveVault.toString()` is redacted (`SensitiveVault(scopeTag=...,entries=...)`). No vault serialization or logging hooks exist.
