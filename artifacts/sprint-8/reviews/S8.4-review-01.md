### 3.3 Workflow Run Lifecycle and State Machine

`docs/sprint-8-agent-contract.md` §3 defines the workflow run lifecycle: `READY` → `GENERATING` → `DISPATCHING` → `VERIFYING` → terminal states (`COMPLETED`, `CLARIFYING`, `REFUSED`, `INCOMPLETE`).

Turn discipline enforces:

1. Composition from stable versioned prefixes, bounded task history, and masked dynamic observations only.
2. Complete-call acceptance only (schema-valid, non-truncated).
3. Pre-dispatch validation against allowlist and trusted scope/revision state.
4. Dispatch through `WorkflowCommandService` / `WorkflowQueryService` with structured feedback.
5. Bounded repair for `Conflict` / `NeedsClarification` / `Denied` / `NotFound`.
6. Mandatory postcondition verification before reporting `COMPLETED`.
