3. **HIGH — Changed source boundaries can silently create another reading.** Source selection binds only an exact-span event (`AgentToolRuntime.kt:285-301`); mutation uses exact-span absence (:490-501, :566-575); `data/EventContextRepository.kt:213-224` uses exact span identity. An alternative overlapping quote of an existing occurrence can be stored as a new event rather than returning clarification/manual review, contrary to design §4.3.
4. **HIGH — Correction can erase previously observed values.** `AgentToolRuntime.kt:490-501` uses the current event only to validate binding; :510-565 constructs a full replacement directly from nullable supplied references and :566-575 writes it. There is no explicit-correction guard for existing non-null amount, temporal anchor or merchant. This contradicts design §6.5's prohibition on silently discarding previously observed fields.
5. **MEDIUM — Declared status nullability is internally inconsistent.** `tools/slm/s8_agent_tools_v3.json:59-62` lists `null` as a type but excludes it from the enum; `AgentToolRuntime.kt:2100-2103` accepts it locally. Strict JSON Schema rejects null while the description and local runtime permit it. The approved §6.3 specifies the non-null enum with `ALL`.
6. **HIGH — Frozen historical input deletion breaks its consumers.** Candidate inventory lines 64-65 deletes `tools/slm/s8_agent_tools_v2.json` and `tools/slm/s8_agent_runtime_skills.json`; `tools/slm/README.md:422-425` calls v2 byte-identical historical evidence, while `tools/slm/s8_agent_runtime_v3_preflight.py:161-168` and `tools/slm/s8_agent_qualification.py:70-72` still load them. 7. **MEDIUM — Classification omits its journal receipt.** The successful classification path `AgentToolRuntime.kt:858-892` returns `AgentEnvelope.ok` without `operationRef`, unlike the event/link mutation paths at :613 and :794. Thus the just-settled journaled classification cannot be selected for explicit same-run replay as required by design §§6.10 and 7.2.
