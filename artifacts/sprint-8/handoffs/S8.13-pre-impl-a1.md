## Material decisions and rationale

- **Expected absence**: strict `null == absent`; design gap fixed atomically in the repository transaction. UI passes the event revision or null only when the span is empty, so compatible.
- **Replay**: model-facing replay is `replay_operation(operation_ref)` through the domain journal (scope/command/digest), not resending old arguments. Historical six-case fixtures are unchanged and NOT regraded; future qualification needs a separately approved mapping.
- **Manual Laya**: `MODEL_UNAVAILABLE`/`INPUT_OVER_BUDGET` is a truthful settled attempt (`ClassificationManual` → `ClassificationUnavailable`) and satisfies the review intent; no fabricated suggestion or hosted fallback.
- **Cursor**: revision-bound signature over filters + ordered `(id, reviewRevision)`; mismatch → `CURSOR_STALE` with a fresh cursor. Honest bounded restart rather than pretending an offset snapshot.
- **References**: per-run in-memory only; restart re-establishes operation receipts from the journal and observations from authorized rows. Values from another occurrence are rejected by binding keys; capture-page value refs are not source-grounded.
- **Raw literal in arguments**: `MASKING_REFUSED` terminal before dispatch; no effect. This is stricter than the old repairable refusal and follows the design's privacy rule.
- **Deleted live harnesses**: they encoded the removed five-tool interface and cannot be validated without an unauthorized hosted batch; historical artifacts remain. This is a disclosed reduction in harness count, not in product capability.
