- `@Query` strings use literals, not `$CONSTANT`s: Room KSP 2.8.5 fails with `No property named value was found in annotation Query`; incantation-free literals fixed KSP. Rejected: constant interpolation in annotations.

- v12 test fixture derives DDL from exported `12.json` (like MigrationChainTest) instead of a hand list: hand lists drift (missing `index_note_events_resolvedTransactionId` caused the only migration-test failure).
- Live retry bounded to one repeat after an honest terminal `Refused(user_decision_required)` caused by model sending `userOverride` as string `"null"`; the passing attempt is the evidence, the refusal is retained in the worker record.
