## Discriminating checks and outcomes

- The requested Bonsai umbrella name was checked directly; direct reader fetch produced HTTP 401. Hypothesis that this is itself a public model card rejected; exact 4B/9B repository names were then separately checked via public Hub APIs and both resolve.
- Gemma candidate size/backend claims were checked against the artifact manifest rather than accepting third-party summary numbers. A QCS8275-specific model file exists, but the phone reports SM6225; no evidence equates these targets, so that variant is excluded.
- MiniCPM identity, template, official GGUF file and file hash/length each resolve at pinned revisions. No model artifact was downloaded or locally rehashed.
- Prior Qwen source and S5 provenance were read. S5 explicitly documents third-party GGUF conversion and defective/paused benchmark/parser evidence; no old quality score is carried into this shortlist.
