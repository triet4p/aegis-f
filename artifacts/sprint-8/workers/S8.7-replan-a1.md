### Contract correction and consumer map

The frozen `tools/slm/s8_agent_tools.json` (`aegis-f-s8-agent-tools/v1`) requires a raw integer for `amountVnd`, whereas S8.6's typed rehydration requires same-session string tokens. One call cannot satisfy both. Separately, v1 has no coordinate translation for source spans after privacy tokens of variable length replace values: offsets into what the model sees cannot be stored-source offsets. The versioned `tools/slm/s8_agent_tools_v2.json` is therefore the one canonical masked-runtime declaration. It defines token strings and UTF-16 offsets into the exact masked source view, requires the exact copied `maskedSpanText`, and the existing `MaskedApplicationEffect` seam verifies/maps boundaries locally before persisting original-source offsets. No raw-value compatibility bypass was added.

Affected consumers are the Gradle-generated Android asset, `S8AgentToolDeclarations` loader, bounded adapter/schema validation, unit and instrumented tests, `tools/slm/README.md`, and `docs/sprint-8-application-tools.md`. v1 schema, evaluation script and historical v1 fixture versions remain unchanged. Operation keys are host-owned and excluded from v2 tool arguments; additional model-supplied fields are rejected, not ignored.

### Behavior and safety

- Trusted `WorkflowToolSession` supplies `AgentSession`, matching S8.6 vault/boundary and host operation key. Capture/draft IDs are checked against trusted scope before reads/effects; cross-capture and nonexistent IDs in the same caller session yield the same scope refusal. Model-provided operation identity is not accepted.
- Masked source, current event/context/link state and query result fields are structured and masked before they can return to a provider. Draft observations include the current `reviewRevision`; stale event/link/draft revisions are service conflicts and current context can be observed again. Event spans cross the privacy seam in masked UTF-16 coordinates, then persist in original text coordinates; partial token boundaries and stale/mismatched copies are refused.
- Amount/date/time values are rehydrated only through the same session's typed vault mapping and local validation. Proposal evidence remains app-owned; non-null user override, confirmation, dismissal, delete, SQL, shell, general filesystem, plugins and device automation are unavailable. Classification calls the real `LayaClassificationEngine`; no category, financial confirmation or ledger row is selected or written by the adapter.
- Retry reuses the host-bound key and delegates to the durable command service. A different payload conflicts; it never silently creates a new key/operation.
