## Worker Result

### What was implemented

- **`app/src/main/java/io/github/triet4p/aegisf/agent/BoundedWorkflowExecutor.kt`** — the
  production multi-turn loop.
  - Trusted host surface: `WorkflowRunHost` (AgentSession scope, S8.6 boundary, the
    `MaskedHostedGateway` **only**, the five current v2 declarations, the S8.8 runtime skill
    catalog, real commands/queries, trusted key source, clock), `WorkflowRunRequest`, and
    `WorkflowRunLimits` (`maxTurns`, `maxToolCalls`, `maxContextCharacters`, `maxWallClockMillis`,
    `maxRepeatedIdenticalCalls`, `maxCaptureObservations`). The per-model output budget remains the
    host's frozen S8.5 `HostedGenerationBudget` (live slice: 8192); no shared cap is introduced.
  - Deterministic states `READY → GENERATING → DISPATCHING → … → VERIFYING → COMPLETED` with
    terminal `CLARIFYING`, `REFUSED`, `INCOMPLETE`, and a bounded content-free trace.
  - Protocol continuation is preserved (one result per pending call, protocol-owned items carried
    through the gateway). Only `HostedToolCall.dispatchable` calls execute; unknown/malformed/
    schema-invalid/truncated/filtered calls get structured `not_dispatched` observations and never
    reach the application.
  - Per-run trusted operation keys: one key per distinct mutation request, reused for an identical
    repeat (application replay/`NoChange`), never model-supplied.
  - Budgets stop honestly before a request or before any call of a turn (no partial dispatch);
    an over-budget turn dispatches nothing; repeated identical calls stop as `LOOP_DETECTED`;
    `Incomplete`/`ContentFiltered` turns end without dispatch; gateway masking-blocked turns end as
    `MASKING_BLOCKED`.
  - Clarification: application `NeedsClarification` suspends the run; `resume` re-reads scoped
    observations and starts a fresh bounded resumed turn from a masked summary of prior outcomes
    plus the user's masked answer (provider-private continuation is not persisted; the summary is
    the S8.10 seam), restarts the wall-clock base (waiting for a person is not agent work), and can
    be used once by its own executor.
  - Terminal refusal at the stated boundary: `user_decision_required`, `caller_scope`,
    `privacy_boundary_refused`. A mistyped scoped token is repair-only (nothing dispatched, the
    model may correct it).
  - Completion verification re-reads application state: event id + exact revision, proposed link
    state/revision, accepted link id/revision, a non-stale classification snapshot at/after the
    dispatch with the draft's review status/revision unchanged, and one `workflow_operations` row
    per applied/no-change mutation. Any attempted mutation that did not apply prevents completion;
    each requested intent must have its verified effect. `Completed` reports only the re-read
    effects, never the model's claims.
  - Initial/resumed prompts supply exact masked source lengths so a span is formed from real
    offsets; no raw content is added.
  - Suspend-only; no blocking work on the caller's thread, and nothing in intake/manual work
    depends on it.
- **`app/src/test/java/io/github/triet4p/aegisf/agent/BoundedWorkflowExecutorTest.kt`** — 16
  deterministic consumer tests (real Room/services/tools/journal/engine; provider scripted at the
  adapter seam): read→update→propose→attach verified completion; false success; refused mutation;
  vanished-effect re-read; loop/turn/tool/context/time budgets; unknown/malformed calls; truncated
  turn; inbound raw-literal block; injected authority; clarification suspend/resume + one-shot +
  foreign-executor refusal; idempotent repeat; real unavailable Laya.
- **`app/src/test/java/io/github/triet4p/aegisf/agent/S89ExecutorLiveSmokeTest.kt`** — one real
  hosted slice, gated by `AEGIS_S89_LIVE_EXECUTOR_SMOKE=1`, synthetic fixtures, durable masked
  evidence.
- **Docs/changelog:** `docs/sprint-8-agent-executor.md`; `CHANGELOG.md` user-visible entry;
  `docs/sprint-8-application-tools.md` pointer to the executor. No plan/status edits.
