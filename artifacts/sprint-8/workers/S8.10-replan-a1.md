## Worker Result

### What was implemented

- **Durable history** (`AgentRunHistory` + Room v13):
  `agent_runs` (run identity = one-way fingerprint of masked request, lifecycle
  PENDING/RUNNING/CLARIFYING/SUCCEEDED/FAILED/CANCELLED), `agent_run_attempts` (one row
  per bounded attempt under its own trusted key; allowed refs only: event id+revision,
  link id+state+revision, draft id+decision source; privacy-safe masked observations),
  `agent_conversation` (user-visible USER/STATUS/AGENT lines, display order). No
  credentials, mappings, continuation items, reasoning, or wire detail are columns
  anywhere. Business captures and `workflow_operations` are never written or exported
  by the history; cancelling/deleting the conversation never touches them.
- **Bounded retry/reconciliation** (`CanonicalAgentRetryPolicy`, `AgentRunFailure`):
  max 3 attempts; `Retry-After`-honoring backoff; 50 newest runs per session; one-way
  fingerprints replay a repeated send onto the same run. Transport/timeout/rate-limit/
  server/stale-revision/schema-repair/uncertain-write reconcile first (journal row +
  live rows re-read: match → `Applied`, missing/moved → `NotApplied` under a fresh key,
  pending/unreadable → `Unknown`, never replay); truncation/filter/masking/
  scope/user-decision/loop/budget never retry. Cancel settles the attempt and marks the
  run without claiming rollback; late replies under old tokens cannot settle; reopen
  revalidates revisions from fresh observations and keeps mappings only in the session
  vault (never persisted).
- **Production wiring**: `startTracked` (admit → claim → run → record → reconcile → bounded
  retry), `startWithAttemptKey` (per-command fixed keys: `key:update/propose/attach/
  classify`, so same-command replays are idempotent no-change and cross-command keys
  never collide), `cancelTracked`, and the adapter's fixed-key path that bypasses the
  read-time replay check and lets the command journal be the replay authority. The
  migration `MIGRATION_12_13` adds the three empty tables (Room schema `13.json`
  exported); older rows/identities/totals are untouched.
- **Docs/changelog**: new `docs/sprint-8-agent-history.md` (full contract), executor doc
  S8.10 pointer + proven summary, user-visible `CHANGELOG.md` entry. No plan/status edits.

### Secure test launch procedure (synthetic fixtures only)

Runtime credentials are process/ephemeral only: the host live smoke reads the
developer `.env` in-process (key names only in this record:
`GOOGLE_AI_STUDIO_KEY`, `OPENCODE_GO_API_KEY`) and the durable evidence records URL,
header **names**, masked request/response bodies, and outcome — never values, hashes,
or digests of the credential. The device scenario carries **no credential** (scripted
provider seam; the app manifest declares no `INTERNET` permission, so no socket can be
opened). Durable records mirror the S8.3/S8.7 synthetic conventions: isolated packages
only (`.s810evidence`, reverted), no personal data, no user database read/reset, no
