## Worker Result

### What was implemented

- **Stable versioned prefix** (`AgentContextManager` + executor `systemInstruction`):
  identical instruction bytes for identical intents (skills render in catalog order;
  S8.11 `context_block_version` block appended verbatim). Dynamic masked observations
  stay at the end of the prompt. Proven byte-identical across all 7 live turns
  (system, user, and tool declarations).
- **Value-free cache identity** (`AgentCacheKey`, `HostedProviderIdentity`,
  `MaskedHostedGateway.cacheKeyFor`): protocol/host/model/frozen-budget from the
  validated adapter config, canonical tool schema, selected versioned skills, vault
  scope tag. No prompt text, raw values, mappings, keys, or credentials — nothing is
  sent anywhere; any stored prefix cache is provider-owned. A provider switch starts a
  fresh native chain from the same stable prefix (no continuation crosses providers).
- **Actual usage, never estimates** (`AgentRunUsage`, outcome `usage`,
  `AgentContextManager.classifyCacheSupport`): per-turn input/output/reasoning/cached
  tokens exactly as each provider reported; absent fields stay null. Behavior:
  `CACHED_PREFIX_REUSE` on any positive cached-input report, `NO_CACHE_REPORTED` on
  reported usage without cached input, `USAGE_UNSUPPORTED` otherwise. History's safe
  observation carries summed totals + derived support + cache fingerprint prefix +
  compaction record; the safe export is unchanged (still excludes keys, digests,
  mappings, credentials, reasoning, wire detail). No schema change was required.
- **Bounded local compaction** (drive loop, dispatch-turn path, resume seam):
  keeps every dispatch record and re-reads mutable state fresh; drops only older masked
  tool-result payloads from the accounted prompt, with a `compaction` record on the
  outcome and history. Summaries (bounded to 32 recent dispatch entries) never authorize
  state; when no older payload exists, the run stops honestly instead of looping.
- **Provider adapters**: each of the three real adapters exposes its validated config
  identity (`providerIdentity()`); the gateway surfaces identities only, never the
  transport/credential/raw text. No explicit cache resource is ever created; no single
  caching mechanism is assumed.
- **Test-harness gate forwarding** (`app/build.gradle.kts`, test-only): the
  `AEGIS_S811_LIVE_SMOKE`/`S811_ATTEMPT` gate reaches the test JVM via explicit
  `tasks.withType<Test>` systemProperty propagation (`-P` flag or daemon env).
  Required because this host's sandbox blocks ad-hoc shell exports from reaching the
  long-lived Gradle daemon (proven: child processes do not inherit `set` vars here).
  Env remains the documented primary gate; values are flags/ids only, never secrets.
- **Docs/changelog**: `docs/sprint-8-agent-executor.md` S8.11 seam updated,
  `docs/sprint-8-agent-history.md` gained an S8.11 section (usage/cache/compaction +
  no-schema-change rationale), user-visible `CHANGELOG.md` entry. No plan/status edits.
