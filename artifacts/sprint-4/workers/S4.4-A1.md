- **Observable result:** Added a production `LayaRuntime.suggest` consumer contract over current category rows, exact caller-supplied correction rules, current stable ids, and calibrated model choices. No-evidence, empty, and invalid cases return typed manual/unknown outcomes rather than a category id. Resolve the returned `Decision` through `LayaCandidatePlanner.resolveCurrent(decision, freshCategoryRows)` before display or further use. A `Decision.Unknown` is a typed no-fit/manual outcome, not a reserved category id. The category table stores names only; oversized retrieval therefore uses lexical category-name evidence, not descriptions or aliases. Incomplete retrieval carries active/offered/omitted/evidence counts.
