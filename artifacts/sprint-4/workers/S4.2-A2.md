## Decisions and rationale

- Checked-in PowerShell helper as the fix vehicle: the assignment explicitly permits it; it is the simplest reliable user-run solution because it encodes pins, ordering, narrow permissions, stale-clear, polling, and JSON validation in one runnable artifact instead of hand-typed steps. Windows PowerShell 5.1-compatible; repo root derived from `$PSScriptRoot` so it works from the documented invocation.
- Rejected `chmod -R 777`: world-writable staging gives every on-device UID write access to a 1.7 GB model bundle the app then executes. `755` on the staging dir (traverse) + `644` on the four staged files (read) is the narrowest mode set that lets the app UID read through `run-as cp` under Windows PowerShell binary I/O with no stdin/run-as piping tricks. Verified as command-generation paths in smoke (fake adapter accepted them; real-device read outcome stays user-observed).
- Stdin/run-as piping instead of staging was considered and rejected: pushing 1.7 GB through `adb shell` stdin from Windows PowerShell risks binary corruption and offers no hash check on the device side; the staging path keeps `adb push` (reliable binary transfer) plus pre-transfer host hash proof.
- Hash-first, device-second ordering: a corrupt 1.7 GB transfer wastes tens of minutes on-device; exact size + SHA-256 against PROVENANCE.md pins gate everything.
- Stale-clear-before-launch (not timestamp comparison): the probe report carries no run nonce, so deleting `S42-parity-report.json` before `am start` is the only way the retrieved JSON provably belongs to this run. Timeout text says so explicitly.
- FAIL/NO_RUN saved verbatim: a non-PASS report is still evidence (missing/corrupt cause or honest misses); the helper never substitutes, tunes, or suppresses it.
- Report saved BOM-free (`UTF8Encoding($false)`): PowerShell 5.1 `[Text.Encoding]::UTF8` emits a BOM that breaks strict host-side `json.loads`; the helper also re-parses the saved file as its own write check.
- Report default destination `artifacts/sprint-4/reviews/S42-parity-report.json`: matches the R1 procedure's save path and keeps the pending physical evidence next to its review gate without touching Main's supervision state.
- Poll defaults 5 s / 300 s: covers the R1-estimated 45–90 s cold load with headroom; overridable via `-TimeoutSeconds`.
- No provisioning UI or S4.3 scope: the helper is a one-shot verification transfer, not an app feature; `LayaRuntimeContract.BUNDLE_FILES` is referenced, never changed.
