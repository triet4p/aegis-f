## 3. Audit of Round-1 Findings and Bounded Fix Correctness

### 3.1. Finding 1: Instrumented Test Tab Selector Ambiguity (MEDIUM) — RESOLVED

- **Files / Lines:**
  - `app/src/androidTest/java/io/github/triet4p/aegisf/ui/S99ChatUiInstrumentedTest.kt:81, 291, 374, 476-482`
  - `app/src/androidTest/java/io/github/triet4p/aegisf/ui/S99MeasurementInstrumentedTest.kt:941-985`
- **Assessment of Fix:**
  - In `S99ChatUiInstrumentedTest.kt`, direct click calls on lines 81 and 291 were routed through `selectDestination("AI Chat")`, line 374 was routed through `selectDestination("Review")`, and helper `selectDestination` was updated to:
    ```kotlin
    compose.onNode(
        hasContentDescription(description, substring = true) and isSelectable(),
    ).performClick()
    ```
  - In `S99MeasurementInstrumentedTest.kt`, a new `selectTab(description)` helper was introduced with identical `isSelectable()` semantics. `selectDestination()` dispatches to `selectTab("Review")`, `selectTab("AI Chat")`, `selectTab("Notes")`, and `selectTab("Home")`, while `openAnalytics()` selects the Home tab before tapping the Analytics launcher.
  - In Compose semantics, `AegisBottomBar` items configure `.selectable(role = Role.Tab)` with `selected = isSelected` (setting the `Selected` semantics property). In contrast, `HomeLauncherScreen` launcher icons configure `.clickable(role = Role.Button)` with content description `"Open <Destination>"`, without the `Selected` property.
  - Consequently, `hasContentDescription(description, substring = true) and isSelectable()` uniquely matches exactly the one bottom bar tab node and never matches the launcher button.
- **Physical Device Smoke Evidence:**
  - Worker executed `S102Round2SelectorSmokeTest` on physical HONOR ALT-LX2 (API 34) prior to scaffold removal (`artifacts/sprint-10/evidence/S10.2-a2/device/selector-smoke.txt`):
    - `AI Chat ambiguous=2 tab=1 -> ASK THE HOSTED AGENT`
    - `Notes ambiguous=2 tab=1 -> NEW QUICK CAPTURE`
    - `Review ambiguous=2 tab=1 -> REVIEW NOTIFICATIONS`
  - Smoke verified that 2 competing nodes exist on Home for each destination, that the selectable tab matcher resolves uniquely to 1 node, and that navigation reaches the expected screen and returns cleanly.
  - The scaffold test was cleanly deleted and test sources recompiled successfully with `:app:compileDebugAndroidTestKotlin` (BUILD SUCCESSFUL).
- **Regression Analysis:**
  - No assertion logic, timing waits, fixtures, or financial assertions were altered.
  - Production code was not touched.
  - The fix strictly isolates tab navigation without affecting any other UI interaction.
- **Status:** **RESOLVED** (Sound evidence; verified).

## 4. Verification and Contract Evaluation

### 4.1. Design System and Primitives
- **Theme and Typography:** `ui/theme/AegisTheme.kt`, `Color.kt`, `Type.kt`, and `Shapes.kt` implement Material 3 dark/light palettes, semantic financial roles (spending, income, transfer, warning, info), tabular figures, and design token radii.
- **Exact Money Presentation:** `VndMoney.formatAmount` overload supports arbitrary currency suffixes while preserving exact whole-dong grouping. `AegisMoneyText` renders exact figures, `₫` suffix, lower-bound wording (`or more` / `trở lên`) on overflow, and masks numbers as `••• ••• ₫`.
- **Status Non-Color Cues:** `AegisStatusChip` renders tint, vector glyph, and localized text label simultaneously, ensuring states (Confirmed, Needs decision, Dismissed, Attached, etc.) are never communicated by color alone.
- **Vector Icons:** `AegisGlyph.kt` defines 24-unit vector paths for Home, Ledger, Notes, AI Chat, Review, Analytics, Manual, Tag, Settings, Eye, Warning, Check, and Cross.

### 4.2. Navigation Shell and Information Architecture
- **Root Bottom Bar:** 5 root tabs (Home, Ledger, Notes, AI Chat, Review) rendered with `AegisBottomBar`. Selection is indicated by weight, color, and a horizontal indicator pill.
- **Home Task Launcher:** 8 labelled launchers rendered directly on the background surface without enclosing card containers, matching the approved anti-stacking design principle. Review waiting count (6) is badged directly on the launcher and tab. Single-line spending glance with eye toggle displays exact month spending (`0 ₫` or `1,000 ₫`).
- **Child Route Inset & Bar Isolation:** The bottom navigation bar is hidden on all child routes (`showBottomBar = currentStackSize == 0`). Back returns to parent with route state preserved.
- **Unsaved Edit Protection:** `TransactionEditorScreen` tracks form edits via `editedSinceOpen` and presents `AegisDiscardChangesDialog` on back or cancel. Form discard returns cleanly to Home; reopening the form starts fresh.

### 4.3. Interface Localization
- Persisted via `AegisUiPreferencesStore` in `aegis_ui_preferences` (keys `ui_language`, `ui_theme_mode`).
