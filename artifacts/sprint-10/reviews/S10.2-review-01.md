## 1. Executive Summary & Review Scope

Task S10.2 establishes the shared mobile design system and root navigation shell for Aegis, executing the approved S10.1 single-task-per-screen and anti-stacking information architecture:

- **Five Root Destinations:** Home, Ledger, Notes, AI Chat, and Review, hosted within `AegisAppShell` with a single unified bottom bar (`AegisBottomBar`).
- **Eight Home Feature Launchers:** Ledger, Analytics, Notes, AI Chat, Review, Manual Record, Categories & Rules, and Settings, positioned directly on the clean page surface (`HomeLauncherScreen`) without enclosing card stacks.
- **Focused Child Routes:** Deep forms and secondary views (reports/Analytics, manual record form, category manager, settings hub, provider settings, notification settings, record detail/edit, draft detail) hide the bottom navigation bar and maintain independent route stacks.
- **Predictable Back/Up Navigation:** Child routes pop cleanly to parent; non-Home roots return to Home on system Back; Home root exits the app; forms guard unsaved edits via `AegisDiscardChangesDialog`.
- **Shared Design Primitives:** Compose themes (`AegisTheme`, `Color`, `Type`, `Shapes`), 24-unit vector glyphs (`AegisGlyph`), exact-money formatting (`AegisMoneyText` leveraging `VndMoney` with `₫` suffix and masking `••• ••• ₫`), non-color status chips (`AegisStatusChip`), and interface localization (`AegisStrings`, English baseline and Vietnamese parity).
- **Backend and Invariant Preservation:** Exact VND arithmetic, draft confirmation boundary, category provenance, and masking/consent contracts are preserved without changes.

Reviewer `S102Evidence` conducted an independent, read-only audit of the candidate source code, host tests, instrumented tests, and native Android walkthrough evidence captured on a physical HONOR ALT-LX2 phone (API 34, 720×1610).

The assessment concludes that while the production implementation and native visual proof are exceptionally thorough and high-quality, an actionable defect in instrumented test tab selectors (`S99ChatUiInstrumentedTest` and `S99MeasurementInstrumentedTest`) causes ambiguous node collisions against the new Home launchers. In accordance with the shared evidence review protocol, Round 1 closes as **changes_requested** (`FAIL`, `advance: false`).

## 3. Actionable Findings Requiring Correction

### Finding 1: Instrumented Test Tab Selector Ambiguity (MEDIUM) — ACTIONABLE DEFECT

- **Files / Lines:**
  - `app/src/androidTest/java/io/github/triet4p/aegisf/ui/S99ChatUiInstrumentedTest.kt:80, 290, 475-476`
  - `app/src/androidTest/java/io/github/triet4p/aegisf/ui/S99MeasurementInstrumentedTest.kt:945-951`
- **Claim:**
  In `S99ChatUiInstrumentedTest.kt` (lines 80, 290, 476) and `S99MeasurementInstrumentedTest.kt` (lines 945, 948, 951), tab navigation relies on substring content-description matching:
  ```kotlin
  compose.onNodeWithContentDescription("AI Chat", substring = true).performClick()
  compose.onNodeWithContentDescription("Review", substring = true).performClick()
  compose.onNodeWithContentDescription("Notes", substring = true).performClick()
  ```
- **Evidence:**
  On the new `HomeLauncherScreen`, feature launcher icons have TalkBack descriptions generated by `AegisStrings.openLauncher(...)`:
  - `"Open AI Chat"`
  - `"Open Review"`
  - `"Open Notes"`
  When the app is on `HomeLauncherScreen`, both the bottom bar tab item (`contentDescription = "AI Chat"`, role = `Role.Tab`) and the launcher squircle (`contentDescription = "Open AI Chat"`, role = `Role.Button`) match `"AI Chat"` with `substring = true`. When multiple nodes match, Compose's `onNode` throws an `AssertionError: Found multiple nodes with content description containing 'AI Chat'`.
  The worker discovered and resolved this exact ambiguity in `S812HostedSettingsChatInstrumentedTest.kt:47-51`:
  ```kotlin
  private fun selectPrimaryDestination(description: String) {
      compose.onNode(
          hasContentDescription(description, substring = true) and isSelectable(),
      ).performClick()
  }
  ```
  However, the worker omitted this fix from `S99ChatUiInstrumentedTest.kt` and `S99MeasurementInstrumentedTest.kt`, leaving those tests broken if executed against the new shell.
- **Why It Matters:**
  Test suites must remain green, robust, and free of known flaky/broken selectors following architectural cutovers.
- **Confidence:** HIGH.
- **Concrete Correction Required for Round 2:**
  In `S99ChatUiInstrumentedTest.kt` and `S99MeasurementInstrumentedTest.kt`, update tab selection helpers to constrain matches to selectable tab semantics (`hasContentDescription(description, substring = true) and isSelectable()`), or exact content description matching without substring, identical to `S812HostedSettingsChatInstrumentedTest.kt`.

## 4. Verification and Contract Evaluation

### 4.1. Design System and Primitives
- **Theme and Typography:** `ui/theme/AegisTheme.kt`, `Color.kt`, `Type.kt`, and `Shapes.kt` implement Material 3 dark/light palettes, semantic financial roles (spending, income, transfer, warning, info), tabular figures, and design token radii.
- **Exact Money Presentation:** `VndMoney.formatAmount` overload supports arbitrary currency suffixes while preserving exact whole-dong grouping. `AegisMoneyText` renders exact figures, `₫` suffix, lower-bound wording (`or more` / `trở lên`) on overflow, and masks numbers as `••• ••• ₫`.
- **Status Non-Color Cues:** `AegisStatusChip` renders tint, vector glyph, and localized text label simultaneously, ensuring states (Confirmed, Needs decision, Dismissed, Attached, etc.) are never communicated by color alone.
- **Vector Icons:** `AegisGlyph.kt` defines 24-unit vector paths for Home, Ledger, Notes, AI Chat, Review, Analytics, Manual, Tag, Settings, Eye, Warning, Check, and Cross.

### 4.2. Navigation Shell and Information Architecture
- **Root Bottom Bar:** 5 root tabs (Home, Ledger, Notes, AI Chat, Review) rendered with `AegisBottomBar`. Selection is indicated by weight, color, and a horizontal indicator pill.
- **Home Task Launcher:** 8 labelled launchers rendered directly on the background surface without enclosing card containers, matching the approved anti-stacking design principle. Review waiting count (6) is badged directly on the launcher and tab. Single-line spending glance with eye toggle displays exact month spending (`0 ₫` or `1,000 ₫`).
- **Child Route Inset & Bar Isolation:** The bottom navigation bar is hidden on all child routes (`showBottomBar = currentStackSize == 0`). Back returns to parent with route state preserved.
- **Unsaved Edit Protection:** `TransactionEditorScreen` tracks form edits via `editedSinceOpen` and presents `AegisDiscardChangesDialog` on back or cancel. Form discard returns cleanly to Home; reopening the form starts fresh.

### 4.3. Interface Localization
- Persisted via `AegisUiPreferencesStore` in `aegis_ui_preferences` (keys `ui_language`, `ui_theme_mode`).
- `AegisStrings.kt` provides complete English baseline and Vietnamese translation parity for shell titles, launchers, tabs, settings, status chips, and dialogs.
