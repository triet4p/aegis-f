## 1. Scope delivered

- **Five root destinations**: Home, Ledger, Notes, AI Chat, Review — one bottom bar, one label per
  destination, selected state marked by weight and an indicator pill as well as color.
- **Home task launcher**: eight labelled feature icons sitting directly on the surface — Ledger,
  Analytics, Notes, AI Chat (featured), Review (live count badge), Manual record,
  Categories & rules, Settings — plus a single-line exact spending glance with a mask control.
- **Focused child routes**: Analytics (existing reports view and drill-down), record detail/edit,
  manual record form, categories manager, settings hub and its bank-notification and
  hosted-provider children, scoped records list, draft detail. The bottom bar is hidden on every
  child route; Back returns to the exact parent; a non-Home root returns Home on system Back.
- **State**: one saveable route stack per destination, a saveable state per route, hoisted ledger
  filters and reports scope; unsaved edits survive tab switches and activity recreation; a route
  the user leaves is discarded so a form does not resurrect a discarded draft; leaving the record
  form with edits asks for an explicit discard.
- **Shared design system**: light/dark/system theme with an in-app override, design type scale with
  tabular figures, financial semantic colors, exact `₫` money text built on `VndMoney` digits with
  masking and lower-bound wording, 24-unit vector glyphs, labelled feature launchers, status chip
  (glyph + label, never color alone), setting rows, bottom-sheet choice, discard dialog.
- **Language**: English baseline and full Vietnamese parity for shell labels, launcher/tab names,
  settings hub, sheets, status words and the discard dialog; choice persisted.
- **Cutover**: the former four-destination shell (`ui/AppShell.kt`), its Manual hub and its combined
  Chat / Quick Capture wiring are retired. The existing hosted-agent panel moved unchanged from the
  note journal into its own AI Chat destination; the note journal keeps local save/history/edit/
  delete and event handoff.

Not in this task (owned by later tasks): visual replacement of Home/reports/Ledger/detail (S10.3),
note journal and saved-note screens (S10.4), dedicated streaming chat (S10.5), draft inbox/detail
(S10.6), manual/correction forms (S10.7), categories/rules/settings screens (S10.8). Feature-screen
body copy therefore remains in its current language until those tasks.

## 6. Limitations and deviations (disclosed, not silently accepted)

- Feature screens keep their existing visuals and English copy; their redesign/localization belongs
  to S10.3–S10.8, so Vietnamese currently covers the shell and shared primitives. The Analytics
  route intentionally shows the existing reports screen with its own English copy.
- Home's glance is one exact line with a mask control, not the full S10.3 glance bar; the dense
  legacy dashboard cards live only under the Analytics launcher until S10.3 replaces them.
- 1.5× text was verified with an app-scoped density override on the phone, per the plan's
  restriction on system settings; the system font scale remained 1.0. This proves layout/labels/
  touch targets, not a human large-text walkthrough.
- Process death was not forced (`am kill` left the PID alive); restoration is claimed for activity
  recreation only.
- Known bounded test-only issue in the frozen candidate: `S99ChatUiInstrumentedTest` (destination
  clicks at lines 80, 290 and 475–476) and `S99MeasurementInstrumentedTest` (mapping at lines
  945–951) still select a tab by content-description substring, which now also matches the Home
  launcher descriptions `Open AI Chat` / `Open Notes` / `Open Review`; they compile but would fail
  if executed. They were not executed: Chat/UI needs an active hosted provider and the measurement
  test is opt-in and needs a live run/fixtures. `S812HostedSettingsChatInstrumentedTest` had the
  same ambiguity and was corrected to `hasContentDescription(...) and isSelectable()`; it passes.
  This is the one correction I propose if the reviewer records `changes_requested`; it touches those
  two test files only and no production source.
- No human usability speed/tap claim is made; observations are worker-driven.
