## 1. Executive Summary & Sprint Goal

Sprint 10 addresses the product owner's explicit rejection of the current Aegis frontend experience. The owner reported that the current UI is unattractive, rigid, and hard to use, specifically noting that **vertically stacking functional cards on an endless scrolling page is not an acceptable information architecture**. The owner directed a complete UI/UX redesign featuring **clearly labelled feature icons that open focused screens, understandable navigation, and task-specific workflows**, referencing market-leading Vietnamese fintech applications **MoMo** and **VietinBank iPay**, alongside international benchmarks (**Revolut**, **Monzo**).

As the designated designer and vision specialist, `S101Designer` conducted comprehensive primary-source research (including direct visual inspection of downloaded high-resolution mobile app screenshots via multimodal analysis), performed an exhaustive audit of all current codebase capabilities and entry points, authored a complete design system and high-fidelity specifications for all 10 core destinations and 8 state families, built a fully interactive, runnable mobile web prototype, and verified all core user journeys and states using headless Chromium browser automation.

## 4. Mobile Visual Design System & Tokens

A comprehensive visual system specification was established in `artifacts/sprint-10/design/mobile-design-system.md`:

- **Design Tokens:**
  * Light & Dark mode palettes adhering to WCAG 2.1 AA contrast ($>4.5:1$).
  * Semantic roles: Expense (`#E11D48` / `#FB7185`), Income (`#059669` / `#34D399`), Transfer (`#6366F1` / `#818CF8`), Warning (`#D97706` / `#FBBF24`), Info (`#0284C7` / `#38BDF8`).
- **Typography Scale:** Tabular numerals (`font-variant-numeric: tabular-nums`) across all financial figures. Supports Dynamic Type scaling from $1.0\times$ up to $1.5\times$ without text clipping.
- **Ergonomics & Touch Targets:** All interactive elements conform strictly to a minimum $48\times 48\text{dp}$ touch target footprint.
- **Non-Color Status Indicators:** Every financial state combines distinct colors, vector icons (`✓`, `⚠`, `✕`, `🔗`), and explicit localized labels.
- **Insets:** Safe area insets (`WindowInsets.statusBars`, `WindowInsets.navigationBars`, `WindowInsets.imePadding`) are handled cleanly.

## 5. Detailed Screen Specifications & State Matrix

Complete specifications and wireframes for all 10 core destinations are documented in `artifacts/sprint-10/design/screen-specifications.md`:

1. **`HomeScreen`:** Hero Balance Card, Eye privacy toggle, 4-button quick action bar, 8-item feature icon grid, pending review alert, recent transactions feed.
2. **`AnalyticsScreen`:** Dedicated spending analytics, month switcher `< Tháng 11/2024 >`, side-by-side KPI cards, multi-segment category distribution bar, drill-down list, daily spending velocity chart.
3. **`LedgerScreen`:** Full transaction history, search bar, filter chips (All, Chi tiêu, Thu nhập, Chuyển khoản), paginated rows with status tags.
4. **`TransactionDetailScreen`:** Digital receipt card, large amount, confirmation badge, key-value provenance rows, Edit and Delete actions.
5. **`ManualRecordScreen`:** Segmented type picker, large amount input with words subtitle, category swatch grid ($4\times 2$), keyboard-friendly insets.
6. **`CaptureChatScreen`:** Dual-mode note composer (local save vs AI analysis), multi-span event extraction, reversible proposed links with Attach/Reject buttons.
7. **`ReviewInboxScreen`:** Conflict-first review queue (Cần xử lý vs Sẵn sàng), draft cards with bank logos, amounts, and duplicate warnings.
8. **`DraftDetailScreen`:** Digital bank receipt, category dropdown, linked note card with Unlink action, raw bank notification audit box, confirm/dismiss CTAs.
9. **`CategoryRulesScreen`:** Catalog tabs for Categories (Hosted locked vs Custom user editable) and Automation Rules, with add category modal.
10. **`SettingsScreen`:** Settings hub with bank notification listener toggle, allowed bank package whitelist, AI model provider configuration, and masked Keystore vault keys.

### State Family Matrix:
All 10 screens feature explicit visual handling across all 8 required state families: **Normal**, **Empty**, **Loading** (animated shimmer skeletons), **Error** (inline retry banners), **Offline** (persistent local-mode indicator), **Ambiguous** (duplicate/conflict badges), **Stale** (reload sentinels), and **Cancelled** (clean exits).
