## Decisions and rationale

- Kept `TransactionEditorScreen` as the single route entry; all existing callers pass the same
  arguments, so Home/Ledger/Notes/AI routes did not need a shell change.
- The approved 4×2 icon grid assumes a stored category icon. Categories store a name and identity,
  not an icon, so the real grid uses the stable category colour swatch + user label; the full
  picker remains a sheet. No icon capability was invented.
- The render’s merchant/account fields have no backing columns; the form shows the supported
  memo/note and does not invent a counterparty/account contract.
- Date/time stays exact `YYYY-MM-DD`/`HH:mm` in a focused sheet with Today/Now, preserving the
  established validation and device-zone conversion rather than replacing it with a calendar-only
  flow.
- At ≥1.3× the type selector uses two rows (Expense/Income, then Transfer) because a real 1.5×
  capture clipped “Chuyển khoản nội bộ” in three equal columns.
- Source identity is saveable as event id + revision and re-read on recreation, so a selected or
  route-supplied note cannot silently detach after a configuration change.
- Save catches an unexpected write exception and shows the localized refusal with Save enabled for
  retry, rather than crashing or claiming success.
