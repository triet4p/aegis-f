## Tried and rejected hypotheses / harness findings

- **"A missing owner credential blocks S10.5."** Rejected: the owner-corrected `.env` path
  provisions a working DeepSeek route through the existing encrypted store and pushed-file
  convention.
- **"The installed app shell can host the live request safely."** Rejected: the shell builds its
  scope from the package database; notification reconciliation copied owner drafts into the
  isolated package. The approach was discarded and the copies cleared; an explicit empty-scope
  host over a dedicated file database replaced it.
- **"A bare sleep/poll after Send is enough to wait for the stream."** Rejected by diagnostic
  (`busy=true hostCreated=false durableRuns=0 chunks=0`): the Compose test dispatcher is not
  pumped by `Thread.sleep`. `compose.waitUntil` against a counter fixed admission.
- **"SSE event count is public text progress."** Rejected: private reasoning deltas are SSE events
  but produce no answer text; the composer stayed in waiting. The counter now wraps the adapter
  and counts only `HostedTurnProgress.PublicText`.
- **"Compose semantics can sample a fast real stream and click Stop."** Rejected: semantics reads
  wait for UI idleness, so a fast stream can settle before a partial is observed. Replaced by
  public-fragment counting, two raw live frames and a raw touch at the measured action button.
- **"Burst raw-frame sampling is safe."** Rejected: it perturbed recomposition and the Stop tap
  landed while the composer still painted Send; discarded.
- **"Raw Markdown/mask tokens are acceptable in the conversation."** Rejected after personally
  viewing real captures; fixed as above and re-verified on the numeral path.
- **"A stopped partial is stored durably."** Observed: only completed answers are conversation
  rows; a CANCELLED run keeps the user turn and a cancelled status. Disclosed, not fabricated.
