## Applicable states and justified N/A

The linked [S10.9 state matrix](../S10.9-a2/coverage-matrix.md) section 2 is the authoritative row-by-row ledger for **normal, empty, loading, error, offline, ambiguous, stale, and cancelled** on all 11 primary destinations. It names the actual capture/test for each applicable state and gives the reason for each N/A; the review accepted those boundaries. No prototype state or generic design matrix is used to fill an unobserved native state.

| Destination | State evidence carried forward | Explicit justified N/A / observation boundary |
| --- | --- | --- |
| Home | Normal, empty, transient loading, read error, privacy masking, route walk, large text | Offline is N/A because the glance is local; ambiguous is N/A because one exact aggregate is shown; cancellation is N/A because there is no dismissible Home alert. |
| Analytics | Normal, empty, transient loading, read error, long-list totals, scoped drill | Offline is N/A for local records; ambiguous is N/A for exact category sums; no stale badge is specified (retry re-reads); no dismissible operation exists. |
| Ledger | Normal, empty, loading, read error, search/filter, page retention, long list and exact boundary amounts | All applicable local-list cases use S10.9 cross-flow and dedicated S10.3 evidence; clearing filters is the exercised cancel/reset behavior, not a synthetic cancelled screen. |
| Transaction detail | Normal receipt, missing record, loading/read error, edit conflict, guarded delete/abort | Offline is local-only; ambiguous is N/A for one stored receipt. |
| Manual record | Normal/empty form, saving, validation/error, offline save, note-event/source choice, stale source/record, discard | Loading is transient; conflict fixtures are isolated; no live bank event is implied. |
| Notes / saved-note children | Empty/composing/saving/error, local offline save, long text, revision conflict, discard, saved/edit/detail and source-link choices | Loading is transient. Failure/concurrency cases use isolated storage; accepted production-shell walk and isolated fixture assertions are separate evidence classes. |
| AI Chat | No-provider/empty, waiting, streamed/completed, Stop, history/re-entry, clarification/link cards, stale context, provider failure/retry, offline and 1.5× | Scripted cases prove UI state only; only S10.5/S10.9-a2 links establish actual authorized-provider behavior. A durable cancelled run does not restore its partial answer text (accepted limitation). |
| Review inbox | Normal uncertainty-first grouping, empty, transient loading, read error, ambiguous/duplicate, refresh and dismiss | Offline is N/A as a distinct network condition because review reads local rows; loading is observed transient, not fabricated as a still. |
| Draft detail | Normal, missing/terminal, transient loading, read error, ambiguous link, stale preview/recheck, cancel, dismiss and confirm assertions | Offline is local-only. Exact confirm effects are asserted in tests and separately documented; a preview screenshot alone is not a completed confirmation. |
