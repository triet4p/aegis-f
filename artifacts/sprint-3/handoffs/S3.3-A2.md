## Why this attempt exists

Main's acceptance finding on S3.3-A1: the user's sample supplies a local date/time (`16/10/2026 07:38`) but **no time zone**, and the bank context explicitly says not to fabricate a timezone. S3.3-A1's `parseBankNotification(content, zone = TimeZone.getDefault())` converted that wall clock into `occurredAtEpochMillis` using the device-default zone, silently asserting an instant the bank never stated, and the returned type had no way to record that the zone was the app's rather than the bank's.

**Was the old contract already an explicit bank-local vs caller-conversion distinction?** No. Evidence read in `BankNotificationParser.kt` (pre-correction): the parser took `zone: TimeZone = TimeZone.getDefault()`, called `ManualDateTime.toEpochMillis(dateText, timeText, zone)` itself, and returned `NotificationField<Long>` — the conversion happened *inside* the parser, and the type carried only a `Long`, so nothing distinguished the bank's statement from the app's zone choice. The listener called it with no argument, so the default applied silently in production. The KDoc's "never the bank's own zone" sentence was documentation only and could not be checked by a consumer. That is an implicit default, so the stated unsafe inference was fixed.

## Failed / rejected approaches

- **`java.time.LocalDateTime` as the field type** (the literal wording "wall-clock LocalDateTime") — rejected: `app/build.gradle.kts` has `minSdk = 24` and no core-library desugaring anywhere in the build, and `ManualDateTime`'s KDoc records that the project deliberately uses `java.util` dates for exactly that reason. Introducing `java.time` into production code would break API 24/25 devices, and enabling desugaring would be an unearned build-scope change. Chose a project-owned `BankStatedMoment` holding the manual-entry grammars instead.
- **Keeping a `zone` parameter with a documented "app policy" default** — rejected: the default is exactly what masqueraded as bank data; the parser must not convert at all.
- **A single-value provenance enum for "zone unstated"** — rejected as unnecessary framework; the absence of any zone or instant in the returned type *is* the structural provenance, documented on `BankStatedMoment` and `Parsed.occurredAt`.
- **Dropping the impossible-date refusal** — rejected; kept by reusing `ManualDateTime.dateError`/`timeError` so `30/02/2026` still becomes `Unresolved(Unreadable)`.
